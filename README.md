# Dr. Armanto Sutedjo — Academic Digital Portfolio

This repository hosts the multi-page, WCAG 2.1 AA/AAA accessible academic portfolio for **Armanto Sutedjo, Ph.D.** on GitHub Pages.

## Folder Structure

```text
├── index.html                  # Landing Page & Overview
├── nexus.html                  # Interactive Research–Teaching–Practice Diagram
├── research.html               # Research Statement & Funded Grants Table
├── publications.html           # Filterable Publications & Conference Papers
├── teaching.html               # Teaching Philosophy & Graduate Courses Taught
├── service.html                # Faculty Development & Professional Service
├── css/
│   └── styles.css              # Shared Accessible Stylesheet (Dark/High-Contrast/Atkinson)
├── js/
│   └── app.js                  # Automatic Markdown (.md) & JSON Loader
└── content/                    # EDIT YOUR TEXT HERE (No HTML required!)
    ├── overview.md             # Plain-text paragraphs for the Overview page
    ├── research.md             # Plain-text paragraphs for the Research Statement
    ├── teaching.md             # Plain-text paragraphs for the Teaching Philosophy
    ├── service.md              # Plain-text paragraphs for Faculty Development & Service
    └── portfolio-data.json     # Structured list of Grants, Publications, Courses & Service
```

## How to Edit Your Content on GitHub (Without Touching HTML)

1. Open the **`content/`** folder in this GitHub repository.
2. Click on any `.md` file (`overview.md`, `research.md`, `teaching.md`, or `service.md`).
3. Click the **Pencil icon (Edit this file)** in the top-right corner on GitHub.
4. Edit your paragraphs in plain English:
   - Use `# Heading` for main titles
   - Use `## Subheading` for section headers
   - Leave a blank line between paragraphs
   - Use `- item` for bullet points
5. Click **Commit changes...** — your live website will automatically fetch and display your updated text within 30 seconds!
